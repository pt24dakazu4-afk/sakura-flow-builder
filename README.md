# 業務フロー作成ツール
入口ページ：https://pt24dakazu4-afk.github.io/sakura-tools/


さくら通り整形外科クリニック（医療法人Eternabloom）の院内向け、業務フロー図の作成ツールです。
ブラウザだけで動く静的ページで、インストールもアカウント登録も不要です。

関連ツール：
- [採用マネジメントツール](https://github.com/pt24dakazu4-afk/sakura-recruit-manager) … 採用フロー・計画・KPI・施策
- [スタッフ人事台帳（ラダー・教育管理）](https://github.com/pt24dakazu4-afk/sakura-staff-ladder) … 人員・ラダー・教育の状況確認

## できること

| 機能 | 内容 |
|---|---|
| 工程の作成 | 「開始 / 作業 / 確認 / 判断 / 注意 / 終了」の6種類から選んで工程を積み上げます |
| 担当の割り当て | 受付・看護師・医師・放射線技師・理学療法士・事務などを工程ごとに設定できます |
| 分岐の記載 | 「判断」の工程には「はい」「いいえ」それぞれの進み方を書けます |
| 並べ替え | ▲▼ボタンで工程の順番を入れ替えられます |
| テンプレート | 院内マニュアルをもとにした8種類のフローが入っています（下記） |
| 印刷・PDF | A4縦で印刷できます。編集画面は印刷されず、フロー図だけがきれいに出ます |
| 保存・読込 | JSONで書き出し／読み込みができます。ファイルとして保管・共有できます |
| Mermaid出力 | Notion・GitHub・Claudeなどに貼り付けると図として表示される記法で書き出せます |
| 設定の編集 | 工程の種類・担当者・テンプレートを画面上で追加・編集できます（下記参照） |

## 収録しているテンプレート

既存の院内マニュアル（2026年7〜8月作成）をもとにしたフローが入っています。

> **このWeb版には、診療報酬の算定ルールを含むフローは収録していません。**
> クラーク業務・自賠責書類・X線照射録のフローは、院内配布版（Google Drive）に入っています。

### 受付・事務・検査

| フロー | 担当部署 | 工程数 |
|---|---|---|
| 来院時の受付対応 | 受付 | 10 |
| 自動精算機でのお支払いの案内 | 受付 | 9 |
| 初診時の診察券作成 | 受付 | 5 |
| MRI検査の案内 | 受付・看護 | 7 |
| 外来様式1作成支援ソフト（セルフ）の入力 | 事務 | 8 |
| リハビリ受付での診察券確認とカルテ入力 | リハビリ受付 | 7 |

担当はスタッフの個人名ではなく職種で記載しています。
内容の修正は「設定」タブ、または `config.js` の編集で行えます。

### 収録していないもの

次のフローは、診療報酬の算定ルールや取引先名を含むため、このWeb版には収録していません。院内配布版をご利用ください。

- 自賠責保険書類の仕分け・管理
- X線照射録の記入・入力
- クラーク業務 8本（外来管理加算／SOAP入力／診察室対応／サポーター／ギプス／画像診断／注射・穿刺／骨粗鬆症）

また、クラークマニュアルのうち「医療用語・略語」「部位別疾患とテスト法」「院内処方薬一覧」は、手順ではなく参照用の一覧のため、フロー化していません。

## 使い方

1. 公開URLを開きます
2. 「テンプレート」から近いものを選ぶか、「＋ 工程を追加」で一から作ります
3. 左側で編集すると、右側のプレビューにすぐ反映されます
4. 完成したら「印刷・PDF」でA4に出力、または「保存 / 読込」でJSONを保管します

工程をクリックすると編集欄が開きます。もう一度クリックすると閉じます。

## 自分で項目を追加・修正する

上部の「**設定（項目の追加・編集）**」タブで、コードを触らずに次のものを変更できます。

- **工程の種類** — 表示名・色・形（通常／角丸／破線）を変更、追加、削除
- **担当者の候補** — 受付・看護師・医師などのリスト
- **テンプレート** — いま編集中のフローをそのままテンプレートとして登録できます

この画面で変えた内容は、**そのブラウザにだけ**保存されます。

## 変更を全員に反映する（config.js の書き換え）

設定を院内の全員の初期状態にしたい場合は、`config.js` を書き換えます。GitHubの画面上だけで完結します。

1. ツールの「設定」タブ →「**設定を書き出す**」を押す
2. 出てきた内容を「コピー」する
3. GitHubでこのリポジトリの `config.js` を開く
4. 右上の**鉛筆アイコン**（Edit this file）を押す
5. **中身をすべて選択して削除**し、コピーした内容を貼り付ける
6. 下の「**Commit changes**」を押す
7. 1〜2分待つと公開ページに反映されます

反映されない場合は、ブラウザで「設定」タブ →「初期設定に戻す」を押してください。ブラウザに残っていた古い設定が消えて、`config.js` の内容が読み込まれます。

`config.js` はブラウザにキャッシュされないよう毎回読み込み直す作りにしているので、ページを開き直せば最新の内容になります。

### 直接 config.js を編集することもできます

テンプレートの文章を少し直したいだけ、といった場合は `config.js` を直接編集するほうが早いです。
JavaScriptのファイルなので、**カンマ「,」と括弧の対応が崩れるとツールが開かなくなります**。不安な場合は書き出し機能を使ってください。

万一ツールが開かなくなった場合は、GitHubの Commits 履歴から一つ前の状態に戻せます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | ツール本体（HTML・CSS・JavaScript） |
| `config.js` | 工程の種類・担当者・テンプレートの設定。**普段はこちらだけ編集します** |

## データの扱い

- **入力内容はブラウザ内（localStorage）にのみ保存されます。** サーバーへは一切送信されません
- 同じ端末・同じブラウザで開けば、前回の続きから編集できます
- 別の人と共有する場合は「保存 / 読込」でJSONを書き出して渡してください
- ブラウザの履歴・サイトデータを削除すると、保存内容も消えます。**大事なフローはJSONで保管してください**

## 患者さんの個人情報について

**このツールに患者さんの個人情報を入力しないでください。**

氏名・カルテ番号・生年月日・住所・電話番号・診療記録などは入力対象外です。
本ツールは業務手順を記述するためのものであり、個別の患者さんの記録を扱うものではありません。

## 公開方法（GitHub Pages）

1. リポジトリの Settings → Pages
2. Source を `main` ブランチの `/ (root)` に設定
3. 数分後、`https://<ユーザー名>.github.io/sakura-flow-builder/` で公開されます

検索エンジンにインデックスされないよう `noindex` を設定しています。

## 動作環境

- Chrome / Edge / Safari / Firefox の最新版
- 外部のライブラリやCDNを一切使っていないため、オフラインでも動作します
- スマートフォンでも編集できますが、作成はパソコンを推奨します
